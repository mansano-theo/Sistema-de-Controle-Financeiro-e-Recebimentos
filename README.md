# 💰 SCFR - Sistema de Controle Financeiro e Recebimentos

Sistema desenvolvido em **C** para gerenciamento de clientes, vendas, parcelas e recebimentos.

O projeto foi desenvolvido como uma aplicação de terminal, utilizando conceitos fundamentais da linguagem C e recursos de controle financeiro.

## 🚀 Funcionalidades

* 👤 Cadastro e busca de clientes
* 🛒 Registro e consulta de vendas
* 💳 Geração e controle de parcelas
* 💰 Registro de pagamentos
* ⚠️ Identificação de parcelas em atraso
* 📈 Cálculo de juros
* 📊 Relatórios financeiros
* 📅 Relatórios diário e mensal
* 📋 Dashboard financeiro
* ✅ Validação de CPF, telefone, e-mail, cartão e datas

## 🧠 Conceitos utilizados

* `struct` e `typedef`
* Funções
* Vetores e strings
* Estruturas de repetição
* Estruturas condicionais
* `switch/case`
* Validação de dados
* Manipulação de datas
* Cálculos matemáticos

## 🛠️ Tecnologias

**Linguagem:** C
**Compilador:** GCC
